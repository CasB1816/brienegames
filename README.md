# Briene Games

Openbare pagina's voor de spellen van Briene Games, gehost met GitHub Pages.

- `index.html`: overzicht
- `<spel>/privacy.html`: privacyverklaring per spel (link in de Play Console)

Nieuw spel: map `<spel>/` met `privacy.html` (kopieer die van Reaction Tap als basis) en een regel in `index.html`.
